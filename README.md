# Директор по маркетингу: Клик и Масштаб (вертикальный срез)

React 18 + Vite + Tailwind + Phaser 3 + Zustand (сохранение в localStorage).

## Запуск
    npm install
    npm run dev        # игра работает с локальным движком оценки (без ИИ)

## ИИ-судья (Claude)
`api/judge.js` это Vercel serverless-прокси, ключ хранится на сервере.
1. Задеплой на Vercel (Import Git repo или `npx vercel`).
2. В Settings → Environment Variables добавь `ANTHROPIC_API_KEY` (и при желании `ANTHROPIC_MODEL`).
3. Локально ИИ можно проверить командой `npx vercel dev`. Без API/интернета игра сама переключается на `localJudge` в `src/engine.js`.
Добавь лимит запросов на прокси перед публикацией, иначе любой сможет тратить твои токены.

## Что реализовано
5 сценариев Казахстана; 4 сюжетных NPC (Алия, Асель, Нуржан, Диас) с дугами из 3 этапов, отношениями (-3..+3) и критической развилкой в финале; портреты с эмоциями; план из 6 полей; ИИ-судья (Claude) и локальный эвристический движок; юнит-экономика (CAC, LTV, ROMI, Churn, конверсия); дашборд (CAC vs LTV, воронка, расходы по каналам); 2 мини-игры (A/B-свайп, антикризисный SMM); личная зарплата и магазин (бонус к качеству и авторитет); сертификат CMO и Markdown-кейс для LinkedIn; сохранение в localStorage; Phaser-сцена (горы за окном, время суток, дождь/снег, пар, монеты, молния, мимика).

## Деплой с телефона (без компьютера)
1. Загрузи папку проекта в новый репозиторий GitHub через браузер (Add file → Upload files).
2. На vercel.com выбери Add New → Project → импортируй репозиторий (Vite определится сам).
3. Для ИИ добавь переменную `ANTHROPIC_API_KEY`. Без неё игра работает на локальном движке.
